## 最小对照设计

先限定一个真实业务问题及其决策输出，例如某项候选干预应 STOP 还是 CONTINUE。选择未被本项目用于候选筛选的新数据，确认许可、实体独立性、划分和最强相关可复现基线。当前 Abalone 的 804 条留出和所有停止路线继续封存；通用数据适配尚未完成，选定任务后先核对支持范围，不能把新数据直接塞入现有 Abalone runner。

对照为熟悉该问题的人类研究员使用 AI 工具的现行流程；处理组为 ResearchHarness 加必要的人类审批。两组获得相同初始资料、数据访问范围、模型/工具版本和预算上限，彼此不可看到对方的提案、结果或反馈。每组都须先冻结假设和协议，再执行一次获批实验；评分由独立可信评价流程完成，隐藏标签不交给提案者。

共享最终评价集只用于事先注册的两组比较：两组在任何最终反馈前同时冻结候选；不得顺序查看成绩再选第二组候选。若现有隔离和预留机制不支持这个预注册比较单元，必须先完成相应工程审查，不能绕过已用数据拒绝规则。

## 预注册必须补齐的字段

| 项目 | 冻结前要求 |
| --- | --- |
| 假设 | 在质量门槛全部满足时，Harness 降低人工投入且总成本合格；必须为所选任务写出具体版本 |
| 基线与控制变量 | 指定人类流程、相关算法基线、资料/数据、工具版本、硬件、预算与两组角色 |
| 主要指标 | 每项决策的人工活跃分钟数，包含准备、审批、排错、复核和交付；等待时间单独报告 |
| 最小有意义效果 | 由任务负责人在看结果前给出所需的人工时间降低幅度；当前未设数值 |
| 质量门槛 | 在盲化报告上检查决策与冻结证据的一致性、可复算性及业务正确性；评分规则、评审者及分歧处理须预先固定 |
| 成本门槛 | 实际模型费用、计算、存储、数据获取、调参及人工成本；设置与业务相符的总成本上限，缺失费用不得记为零 |
| 重复与不确定性 | 任务数、随机种子、人员分配及区间方法必须依据任务变异和最小效果在运行前确定；单个任务仅作探索，不能支持普遍效率声明 |
| 有效性检查 | 冻结前定义计时缺失、标签泄漏、评分故障等判据；科研负结果不属于测量故障 |

候选算法效果仍适用该任务自己的冻结采用门槛。可信的 STOP 可以是合格研究决策，不能把“得到正结果的数量”替代质量评价。

## 事先规定结果如何改变决定

- 质量不达门槛：停止当前产品方案的采用主张，记录具体错误；不能用省时抵消。
- 质量合格，但人工时间改善低于最小效果，或总成本超限：停止本次效率/成本假设；不得增加调用或改评价标准补救。
- 质量、时间与成本均过线，且预定重复和不确定性要求满足：只允许推进该任务范围的有限试点，不推断可以替代整个职位。
- 预先定义的测量有效性检查失败：记录 INVALID 和原因，不自动重跑；新协议须说明哪些数据已暴露和为何仍可独立评价。
- 样本不足、区间不够确定或必要成本未知：记为证据不足，不宣称通过；不得看完结果后临时增加样本。

每个比较保存协议、基线、原始记录、效果及变异、成本和最终 STOP / CONTINUE（或 INVALID）账本。原始负结果保持不变。

# A2-R1 外部复现：数据资格审查

2026-11-08。**BLOCKED_DATA_QUALIFICATION，尚未注册、批准或执行实验。**

已完成公开来源筛选、首选数据的版本/字段/许可核查、可复查的工况清点和复现协议草案。结论是：**Delft 2023 数据最接近，但现有证据不足以把它称为可直接执行的 A2 独立复现集。** 现在需要审查的是是否推进这一来源的缺失信息与使用许可确认，不是批准开跑。没有读取外部声学标签、训练模型或计算候选分数。

## 数据来源及选择理由

首选 [4TU 数据集 v1，DOI 10.4121/20940646.v1](https://doi.org/10.4121/20940646.v1)，作者 Salil Luesutthiviboon、Lourenco Tercio Lima Pereira。官方研究记录说明它来自两个风洞、两种尺寸的 NACA 633–018 模型，包含直尾缘参考和锯齿改型；不是 UCI/NASA NACA 0012 记录的重新分割。来源独立有文献支持，但还没有完成逐条数据溯源与重叠审计。[官方论文记录](https://research.tudelft.nl/en/publications/aeroacoustic-benchmarking-of-trailing-edge-noise-from-naca-63sub3/)

选择依据是独立采集、直尾缘参考、可下载且带工况 ID 的边界层字段；选择前没有计算任何候选预测或误差。只考虑 `TE configuration == BASELINE`，锯齿/翼尖/动态失速不能拿来补足本复现的样本。原 A2 的成功不是筛选外部标签的依据。

已下载并检查官方 README 两页、LRM/HRM 工况表及 RO-Crate 元数据。声学 ZIP 尚未下载。README 将声学文件定义为 **narrowband SPL**，而 UCI 目标是 **scaled sound pressure level**；名称相近不构成可比性证明。[UCI 原定义](https://archive.ics.uci.edu/dataset/291/airfoil+self-noise)

元数据清点为：LRM 178 个测试记录，其中 67 个直尾缘记录、14 个提供 `delta*`；HRM 分别为 45、18、4。将 clean/forced 和喷口变化聚合到同一模型、名义 Re、迎角后，仅有 **10 个粗略工况组合**。这不是 18 个独立重复，更不是已经合格的 10 个留出工况；最终可用数量要经过边界层语义、风速、声学质量和频段核查。不能把一条频谱的频率点计成独立实验。

## A2-R1 协议草案：若资格全部补齐，才可另行冻结

这是一项固定训练数据的外部迁移复现；不是在外部数据上重新训练再交叉验证。后者会改变研究问题，不能悄悄作为本草案的实现。当前不能从不兼容的目标量得出科学 STOP。

| 项目 | 拟保持的规则 |
| --- | --- |
| 假设 | 原五列追加唯一 `f * delta_suction / u_inf`，在独立风洞数据上继续满足原 A2 的效果、不确定性和成本门槛。 |
| 参考 | A1 选定的固定 Extra Trees，100 棵树，参数与 A2 完全一致；这是与 A2 干预最直接的配对参考，不宣称是外部领域最强模型。 |
| 训练和种子 | 仍只使用原 A1 961 行、67 工况；不合并验证或已消费留出；seed 11/22/33，各 baseline/candidate，六次拟合，不选模型不调参。 |
| 历史有效性 | baseline 仅在原 A1 验证特征上复现历史预测，绝对差 ≤1e-8；不重跑 A1 资格选型，不读取 A2 留出做本轮评分。 |
| 外部输入 | 仅直尾缘、作者确认的字段和质量合格频段，精确 ID、单位换算、排序及目标映射必须在执行审批包中列全。全量一次，没有预览分数、试跑或再分割。 |
| 指标 | 工况内 MAE，再工况等权，dB；同一模型/工况下 clean/forced、喷口及频率相关观测一起处理，不能伪造独立性。最终分组键须随可验证的元数据冻结。 |
| 最小效果 | **每个 seed 改善 ≥0.2 dB**，不因更难的外部分布而降低。 |
| 不确定性 | 对 seed 平均的配对工况损失整组 bootstrap，10,000 次，seed 20261107，95% 下界 >0；同时报告全部 seed 和样本标准差。相同风洞的相关性须报告，不能宣称跨风洞总体置信度。 |
| 成本门槛 | 整批外部数据每模型预测五次取中位数，含候选变换与数组转换；三个 seed 的中位数之和比 **≤1.1**。11/33 baseline-first，22 candidate-first。 |
| 隔离和预算 | 固定 Python 3.12/锁定依赖，CPU 单线程，worker 240 秒、16 MiB 输出、一次尝试；Linux Bubblewrap 或 macOS Seatbelt，选定单一执行位置后绑定审批。无无隔离回退。 |

有效性和处置事先固定：

1. 数据、单位、来源、最低工况、质量或许可不满足：**STOP_DATA_QUALIFICATION**，不拟合、不评分；这是数据方案不合格，不能包装为科学反证。现有未知项暂记 BLOCKED，不猜测通过。
2. 执行前代码/输入/环境/隔离不匹配：拒绝启动。启动后测量无效或中断：记录 INVALID，保留该独立数据源的预留，不自动重试。
3. 测量有效但任一效果、区间或时延门槛不通过：**STOP** 这条固定特征的外部可迁移路线；不换频段、厚度算法、训练数据、模型、种子或阈值补救。原 A2 局部结果仍保留，但不得再声称外部复现成立。
4. 全部门槛通过：**CONTINUE** 仅支持这份外部数据条件下的迁移结果；不自动部署、不证明商业价值或人类替代。

完成资格后才制作精确执行清单与代码摘要，使用新的独立来源消费记录；不能删除、复制或绕过现有 A2 消费记录。拟执行前还需合成数据的隔离、单位、ID 对齐、目标不可见、篡改与重复拒绝检查。当前没有声称这些外部适配已实现。

所有 fit、变换、30 次预测计时、预检、数据下载字节、存储、墙钟、RSS 和人工处理都应分别计入；硬件/能源等无法定价时写未知。准备阶段模型实验调用与拟合均为零；网页检索和本会话研究成本未计价，不视为免费。数据资格补齐不授权云服务支出。

# C7：数据使用暂停及保守交接

2026-11-09。用户已验收 C6，授权继续框架研发，禁止新的研究实验。

冻结资格不等于永久许可。本轮增加本地数据使用暂停账本，以资格包内的
dataset id/version/source 为精确身份，跨基线/候选、用途和资格摘要生效。
人工记录原因及审查者；不改写原接受决定、执行批准、研究结论或消费历史。
暂停不是科学 STOP，也不自动终止已启动的进程。

四个现有执行入口、准备/批准和 tabular 提案入口消费同一账本；执行器在
隔离探针后重新检查，提案 actor 启动前也重查。缺文件表示尚无本地暂停；
损坏、链接或不兼容账本拒绝活动操作。历史只读审计独立于当前暂停。

提供只读状态和离线 export/import。导入只能合并新增暂停，不能清除任何
本地记录；摘要验证不是身份认证。使用现有 checkout 锁，写入原子替换。
没有恢复/解除命令；若将来需要恢复，另行审查流程，不以修改用途或重签
资格解除。身份别名、跨 checkout 实时同步、自动发现许可撤回及运行中撤销
不在本轮范围内。SR 和通用 run 不在覆盖范围。

验证只使用合成软件 fixtures：四入口的批准后暂停与探针期间暂停、不同
用途/重新接受不能绕过、只读历史兼容、损坏与链接拒绝、锁冲突、交接并集
幂等和失败无部分写入、提案不调用模型。完整回归和既有合成隔离 CI 后提交
C7 工程验收。不注册、不运行真实研究。

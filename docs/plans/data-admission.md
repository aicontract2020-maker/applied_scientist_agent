# C5：数据资格接入新建基线的执行前检查

C4 已由用户验收通过。本轮是软件迭代，不授权新的研究实验。

最小接入范围为现有两个封闭数据适配器的新建基线资格检查（Abalone、Airfoil）。不新增训练算法、数据源、候选执行器或无隔离回退。公共 prepare 在解析数据前要求已接受的 C4 包与明确用途；新包将资格证据和人工决定完整嵌入，并绑定适配器、数据身份/版本、用途、分区摘要和固定基线方案摘要。

approve、只读 preflight 和 execute 共用校验；资格接受不能替代基线执行批准。execute 在环境探针前检查，在探针后、预留或创建 run 前重新检查精确包与批准。真实来源缺资格的旧包只允许历史只读读取/审计；不允许靠删除资格字段降级执行。内部合成 fixture 保留，带资格的 fixture 则同样强制验证，用于软件验收。

先验证缺失/未决/拒绝/跨任务/用途不符/篡改/过期批准都在环境检查和 worker 前失败；再用合成数据通过现有隔离 runner，证明资格证据未进入 worker 请求。既有数值门槛、一次执行规则和停止记忆不变。旧候选工作流不扩大授权，未知新数据源仍拒绝。完成本地和远端软件检查后提交 C5 工程验收。

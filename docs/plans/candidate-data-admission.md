# C6：候选阶段数据资格接入

2026-11-09。用户验收 C5，并授权候选阶段工程接入，仍禁止新的研究实验。

两个封闭候选 adapter 使用独立资格标识 `abalone-candidate-v1` / `airfoil-candidate-v1`。基线资格不能自动扩大到最终留出；候选资格的用途必须明确覆盖固定训练、验证复现和一次留出评价。将资格全文、决定、用途绑定到基线证据摘要、所有分区、完整候选和原固定 recipe；执行批准仍独立。

prepare / approve / 新增只读 preflight-trial / execute 消费同一校验。旧真实候选包只能只读审计，不能删字段降级；内部未带资格的合成 fixtures 保持兼容，带资格的 fixture 严格验证。统一 tabular propose 阶段和直接 proposer 在创建研究输出、预留或调用模型前检查资格，并传递到候选冻结；execute 不接受运行时资格覆盖。

保留原 feature review、停止记忆、留出预留、隔离 probe、注册后一次执行和全部门槛。探针后重新比较完整包、数据、基线与批准，并重新检查停止/占用记忆，再预留。完整历史与带资格合成证据都须能只读审计/交接。只使用软件 fixtures 验证失败路径、worker 隔离和 CLI，不读取新的研究数据或发起真实研究。

完成实现、完整回归和 macOS/Linux 合成隔离验证后提交 C6 工程验收；不自动执行科学实验。

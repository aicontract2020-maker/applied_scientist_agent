# C17：批准前的冻结材料摘要

2026-11-20，C16 已验收。本轮不运行研究实验。

增加 task review，显式选择四个需要人工批准的 Abalone / Airfoil 基线或
候选流程。复用原生严格加载器，检查当前源码、数据和候选绑定后，从冻结
内容生成摘要：精确批准摘要、完整固定协议、候选理由/代码、基线协议、
数据分区数量及资格摘要。可编辑 REVIEW.md 不作为依据。

本入口不要求已有执行批准，但也不检查或生成批准；不读取当前停止/占用
记忆，不宣称当前可执行。有效历史材料也可能已消费；原批准和 preflight
必须另行执行。旧源码包、篡改材料和 evidence-only 包拒绝。SR 不套用这套
人工批准格式，显式指向既有 SR 检查。不得输出数据行、标签、预测或文献/
资格全文；全文仍须人工在原包核实。候选仅复算已有基线审计，不训练或预测。

验证：四路合成材料无批准可读且零写入；摘要与原协议精确一致；说明文档
篡改/删除不影响摘要；修改冻结材料/候选/资格/源码被拒；无模型/隔离探针；
未知流程先拒绝、字段边界及 CLI 退出状态。实际隔离合成脚本在批准前检查
摘要，覆盖候选真实历史审计。完成本地与远端验证，推送后交工程审查。

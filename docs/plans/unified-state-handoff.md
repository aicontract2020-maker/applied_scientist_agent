# C8：一次性交接回归排除记忆与数据暂停

2026-11-09。C7 已由用户验收，继续研发；禁止新的研究实验。

新增 `tabular handoff status/export/verify/import`。一个固定格式包包含回归排除
记忆及当前全部数据暂停，不携带原始数据、标签、资格全文或执行批准。旧记忆、
暂停命令保留，但新统一包不能被其中一个旧导入器当作单组件接受。

导出使用现有 checkout 锁，同步快照两组件；导入先完整验证两个组件和与本地的
合并兼容性，再在单个不可覆盖文件上原子发布。两类读取器同时消费该文件，不做
先写一个组件再写另一个组件的半次导入。中断在发布前不生效，发布后两组件都可见；
重复幂等，旧快照不能清除暂停、终局或留出占用。损坏的统一包使活动操作保守拒绝。

明确边界：离线快照，不提供全局锁、签名或新实验批准；没有自动解除暂停。
只含 Abalone 回归排除记忆和 C7 全部数据暂停，不含 Airfoil 试验预留、SR 记忆，
也不代替单独的私有证据包。不声称任意任务的完整交接。

验证只用软件 fixtures：组合一致性、无部分导入、原子发布失败、冲突/超限/链接/
坏摘要拒绝、旧接口互通、陈旧包不降级、四入口仍受暂停约束、原记忆阻止复用、
无模型或 worker 调用。既有合成隔离流程验证真实完成证据可在新状态交接后只读
审计。完整回归和跨平台检查通过后提交 C8 工程验收。

# C16：Abalone / Airfoil 环境诊断

2026-11-20。C15 已由用户验收。本轮仅工程和合成软件验证，不运行研究实验。

问题：顶层 doctor 检查 SR 的图像、Codex 与 actor 环境。固定表格基线/候选
执行共享 .venv-tabular 和隔离 worker，却缺少不依赖 SR 资源的安装诊断。

新增 tabular doctor / airfoil doctor，共用诊断模块。默认检查受支持平台、
固定解释器、原生版本锁、基础科学库导入与隔离工具；不联网、不安装、不准备
材料、不读研究数据或批准。显式 --probe-isolation 才运行原生合成内核探针，
只在前置检查通过后执行一次；失败不给出替代执行方式。缺项逐项报告并返回
非零退出码。默认通过明确不代表内核隔离通过，所有结果均不授权研究。

范围仅限已冻结基线/候选的执行环境，Abalone 的自主提案 actor/Codex 登录
不在其中。保留原 doctor、所有执行入口、科学契约和审批/停止语义。工作流
目录加入相应诊断入口提示，文档给出最小安装路线。

验收：合成单元检查正常/缺安装/错误版本/导入失败/不支持平台/工具缺失/
Linux root/探针失败与异常结果；无探针时不调用内核探针，有失败时不调用。
CLI 输出和退出码准确，诊断不创建研究状态。完成本地完整测试和 macOS
真实探针；远端四组兼容检查和 Linux 完整测试/实际探针通过后推送验收证据。

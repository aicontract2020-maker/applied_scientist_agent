## 安装与环境

测试目录为 `/private/tmp/research harness handoff 20261104`，包含空格且位于 `/Users` 外。源码是本地候选提交的全新 Git clone，不是把原目录/环境复制过去；有自己的 `.venv-sr`、固定上游仓库、模型权重和 100 对 Urban100 图像。pip 使用了正常软件包下载缓存，但没有复用原已安装环境。Python 实际为 3.12.13，原环境为 3.12.14，证明未绑定原解释器绝对路径。

初次软件有效性检查发现 venv 的解释器经过 `~/.local/bin` 中间符号链接，被候选读取边界拦截。修复 bootstrap，让本 venv 的别名直接指向相同的真实解释器，再幂等重跑安装。**当时尚未调用模型、生成候选或评分**。在桌面受限工具中嵌套 Seatbelt 被拒绝，完整探针按授权在正常本机执行环境运行；这不构成重跑科研负结果。

随后 `doctor --network` 全部通过：

- 固定提交、模型/评价源码哈希、权重 SHA-256、全部 100 对数据。

软件测试 64 项通过；离线完整演示成功。直接依赖和实际解析的全部传递依赖分别记录于 requirements-sr.txt、requirements-sr.lock.txt；最终 bootstrap 使用同一版本约束，doctor 检查完整列表。详细原始环境、探针、输入哈希位于 [portability-evidence](portability-evidence/)。

最终约束安装幂等复检、最终 `doctor --network` 与 64 项软件检查均通过；另建无第三方依赖环境，64 项中 61 项通过、3 项可选 SR 检查跳过，离线演示成功。重复使用同一研究 ID 返回 1，账本摘要不变且没有第二次 agent/实验。证据见 doctor-final.json、offline-final.json、final-checks.json。

## 真实自主周期

调用：`.venv-sr/bin/python -m research_harness research --id handoff-validation-20261104`。

实际评分源码提交为 `0847cf8`；完整执行源码快照已归档。最终版本额外冻结了这次实际安装的传递依赖、更新支持范围说明/版本/报告，以及加入本轮已用图像、文献和 STOP，之后重验安装幂等性、环境检查、软件测试和重复 ID 拒绝，不另起第二个科研候选。

Agent 自行实时搜索，读取 [GamutMLP](https://arxiv.org/abs/2304.11743) 的 PDF 提取前 40,000 字符（有截断），以及 [Deep chroma compression of tone-mapped images](https://arxiv.org/abs/2409.16032) 摘要；未预给论文或候选菜单。

它自编 BT.601 保亮度的逐像素越界 RGB 色域压缩：只压缩相对中性灰的色度，使可表示亮度尽量不受逐通道裁剪影响。论文涉及其他成像条件，转用于 SwinIR/PSNR-Y 是 agent 的推断，不是文献证明。机制不同于此前四条 STOP 路线。

新留出 12 张图在搜索前按哈希固定，全部排除 G3/G4；一个合成检查、一次注册、一次真实实验。门槛不变：平均增益 >=0.05 dB，95% bootstrap 下界 >0，延迟比 <=2.5。

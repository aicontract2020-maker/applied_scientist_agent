## 交付行为

换 checkout 后，已预留过的回归自主提案不会因本地缺少旧目录而自动再试。
空预留保守占用；已知基线绑定可补全，冲突拒绝。直接/统一提案入口在模型和
研究输出前检查，隔离探针后重查。原本机启动恢复保留原证据门槛，导入包不
携带恢复权。提案占用不等于科学 STOP 或留出消费，现有候选仍能审查/批准。

统一 v3 四组件同时导入，v1/v2 兼容但显式缺少提案状态；旧包不能释放占用。
完整操作及恢复限制见 [使用说明](PROPOSAL_MEMORY_HANDOFF.md)。

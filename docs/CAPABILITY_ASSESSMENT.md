# ResearchHarness 能力与价值盘点

2026-11-21。审查基准：`da04750d1be589326d7509f545a297b1f005461f`，软件版本 0.35.0。
状态：**现状盘点完成；功能扩展暂停；下一项研究验收尚不可执行。**

本轮只读已有报告、归档账本/审计摘要和源码，并形成判断。没有调用研究 actor、
下载数据、重新评分、拟合或运行新的研究实验。没有重验全部私有原始记录；
下文引用的运行审计是既有审计，不是本轮重新认证。证据路径与文件摘要见
[盘点快照](capability-assessment-evidence/snapshot.json)。

文档核验检查了 66 份来源的摘要与基准提交内容、归档事件计数、图像选择并集
和本地链接。按仓库要求运行的软件测试为 415 项、跳过 16 项、其余通过
（本机默认 Python 3.9.6）；这不新增受支持版本的平台认证或研究能力证据。

## 当前结论

项目已有**受限任务中的研究执行与审计能力**。固定 SR 后处理任务存在研究
actor 独立检索、提案、编码、触发一次实验和报告 STOP 的实例；Abalone
存在独立 actor 提案后、由人另行批准的真实试验。框架能够记录负结果，
保留已用数据，并将隔离、评价和停止规则放在候选代码之外。

还没有证据证明：普遍可靠的研究判断、任意新任务的低成本接入、人类时间
节省、完整成本优势，或客户愿意付费。A2 的一个正结果不能替代这些证据。
当前适当定位是**有实际研究记录的受限原型**；“取代中小公司 Applied
Scientist”仍是尚未验证的创业假设。

## 必须区分的四种贡献

| 角色 | 实际含义 | 不能混计为 |
|---|---|---|
| Harness 内研究 actor | 独立受限会话，读取既定上下文，使用允许的工具提出方案/代码 | 自行定义整个业务问题、数据访问权或采用门槛 |
| 确定性控制器/可信 worker | 按开发者已实现的协议冻结、运行、评分、审计和执行停止规则 | Actor 自己设计了正确实验或自主保障全部科学质量 |
| 本研发会话的协作者 | 我在用户指导下选择任务、查证材料、编写适配器、组织运行并复核解释 | 已打包产品无需维护者帮助即可完成这些工作 |
| 人类用户/审查者 | 决定方向、批准实验、确认工程验收，未来承担领域判断 | 已测量的人工工作时长或客户采用证据 |

研发协作者也是 AI。这里按产品边界区分贡献，不能因为都是 AI 工作，就把
会话中临时开发和操作的能力归到现成 Harness 的自主能力上；也不能把这些
工作都误记成人类亲自编写。

## 研究质量：已看到的缺口

1. **提案理解。** G6 的裁剪与原评价器等价，是已经发生的失败，非假设风险。
   G7 增加有限合成探针和独立语义审查后通过一次新机制审查；这不能推出
   审查器对新任务、复杂空操作或停止路线变体都可靠。
2. **文献与推断。** 多轮只取得摘要和最多 40,000 字符的 PDF 提取文本。
   G4 记录指出“过平滑”不能直接推出对比度扩张降低像素误差；T2 的生物学
   联系也被报告标为薄弱。成功获取文献不是其支持了具体假设的证明。
3. **结果解释。** G3/G4/G7 采用单次推理加后处理，对比双次参考；有效检验
   了采用主张，但不能单独归因于后处理。操作者收窄了原报告的解释；G4
   还纠正了“10,000-image bootstrap”的措辞。报告事实/因果判断尚不能免复核。
4. **基线与现实价值。** 当前基线是各自固定约束下的参考，不是所有相关方法
   中已被证明最强者。0.05 ring、0.2 dB 等是研究前采用的工程门槛，没有客户
   业务价值标定。不能凭达标或 STOP 直接推算企业收益。

上述判断来自相应历史报告及 G6/G7 的 operator-audit；没有修改原结果，
没有追加消融、重新解释通过条件或为失败路线增加实验。

五个工作流 ID 是 SR、Abalone 基线/候选、Airfoil 基线/候选，并非五个通用
数据适配器。通用固定预测评价接口也不等于具备任意数据的隔离训练能力。
将新数据任务接入目前需要专门工程与科学协议工作，不能隐藏为用户填写配置。

## 已经投入的工程有什么意义

隔离与停止约束使一次研究能够产生可审查的负结果，减少无记录的重试空间；
数据资格和保守交接解决了跨用途、跨 checkout 的已知误用问题；安装和审阅
入口降低操作摩擦。这些能力值得保留。

C15–C17 主要增加发现入口、安装诊断和审阅便利。415 项完整软件测试及
跨平台检查支持其实现行为，不测量提出好问题、找到强基线、文献判断、
人工时间或客户价值。继续增长测试数和小功能验收，不会自动减少这些不确定性。

最近研发的机会成本无法可靠量化：本会话与人类投入没有完整工时台账。
不能编一个节省比例，也不能用几秒的 worker 时间或每机时代理费用代替总成本。
T2 提案账单和 A2 实际本地货币费用均有未知字段。后续测量须保留未知，不填零。

## 现在的产品决定

**保留 0.35.0，暂停没有明确验收问题驱动的功能扩展。** 当前不继续追加 SR
小技巧、不重开已停止路线、不以等待外部数据为由继续堆通用框架。

建议先把可检验的交付对象收窄为：**帮助已有研究人员完成一项有界候选研究，
交付一份可核验的采用/停止决定及证据。** 可先考虑受限表格回归范围，但这
只是与已有能力接近的产品假设，不是已选定的高付费行业或已验证市场。

| 产品判断 | 本轮决定 | 改变决定所需证据 |
|---|---|---|
| 有界研究执行原型值得保留 | 保留 | 已有真实轨迹及实现验证 |
| 可以仅凭 brief/data 完成新领域研究 | 当前不成立于已实现接口 | 明确、有限接入工作与一次事先冻结的新任务验收 |
| 研究判断已经可靠，可免复核 | 不作此主张 | 独立评审、明确错误标准及跨任务重复；G6 反例须保留 |
| 相对现行研究流程有经济优势 | 证据不足 | D1 所需人工对照、工时与完整成本 |
| 某行业值得做付费产品 | 证据不足 | 可识别的问题负责人、实际采用决定、价值与付费证据 |

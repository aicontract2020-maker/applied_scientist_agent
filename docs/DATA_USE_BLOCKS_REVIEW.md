## 交付

同一数据身份的本地暂停优先于旧批准和新资格材料，覆盖两个基线、两个候选及
回归提案链。执行器及 proposer 在隔离探针后复查，阻止后续预留和进程启动。
状态损坏时拒绝活动操作；历史只读证据不改写。暂停与科学 STOP、数据消费分别记录。

新增只读状态、精确摘要人工登记、离线导出及只增不减的导入；现有 checkout 锁
保护写入，整包校验后原子替换。没有解除命令，不授权任何新数据或研究。
详细行为、操作和边界见 [数据使用暂停](DATA_USE_BLOCKS.md)。

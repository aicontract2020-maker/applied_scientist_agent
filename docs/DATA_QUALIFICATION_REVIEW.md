# C4 工程验收：数据资格审查模块

2026-11-08，版本 0.22.0。状态 **AWAITING_ENGINEERING_REVIEW**。这是已实现的软件验收材料，不是实验方案，也没有批准任何真实数据来源。

## 可以实际使用的部分

新命令 `data-review` 支持空模板、证据冻结、只读检查和人工决定。八项条件不可省略；未决项保持 BLOCKED，任一明确不兼容进入数据资格 STOP，全部有依据后才待人审。精确摘要上的接受仅得到 `QUALIFIED_FOR_PROTOCOL_DESIGN`；所有输出均不授权执行。明确拒绝与接受均为同一包路径的一次记录，后续命令不能覆盖。

证据发生改动、适用用途被换掉、旧决定移到新包上时检查失败。包包含完整元数据文本，私有保存，可离线交接；正文中的命令、URL 不会执行。原有实验代码、协议门槛、数据预留和停止记忆未改。

同事可按[使用说明](DATA_QUALIFICATION.md)运行纯合成演示，无需真实数据、模型登录或额外 Python 依赖。

## 请审核的具体决定

是否接受以下 C4 工程范围作为后续新任务接入的基础：

1. 新数据先整理固定八项证据；未决或不兼容不能用人工接受绕过。
2. 事实、独立性和适用许可由人核实；工具负责结构、完整性和决定绑定，不自行认证。
3. 数据资格接受与实验批准分开；接受后只能准备协议，研究执行仍须单独冻结并获批。

**验收 C4 不等于授权运行实验或批准 Delft 数据。** 如果接受，下一项工程工作是设计新任务 adapter 对这份记录的消费约定与执行前复查，并保持研究执行另行审批。

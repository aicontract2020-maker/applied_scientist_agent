# 下一道门槛：一个新任务的有用研究决定

2026-11-21。**DRAFT / NOT_READY / NOT_AUTHORIZED**。
依据[能力盘点](CAPABILITY_ASSESSMENT.md)，本页限定下一次应回答的问题及
判定规则。具体任务、数据、人员和预算未确定，不是完整预注册协议；没有
运行模型、招募参与者、联系客户或开启研究实验。

## 要作出的产品选择

拟验证：在明确任务范围和一次有上限的接入投入后，非维护者能否使用冻结
版本，让研究 actor 提出一个可检验候选，交付经独立审阅合格的研究决定，
且不需要维护者在过程中代写候选、修科学解释或改核心执行代码？

通过只支持该任务的有限可行性，允许设计进一步对照评测；不支持取代职位、
普遍省时或商业成功。科学候选最终 STOP 可以完全合格。空干预、误引文献、
不受证据支持的结论或维护者救场，即使代码跑完，也不能算合格交付。

## 已知不能靠运行解决的前提

目前没有任意新数据适配器。禁止把任意 CSV 塞进 Abalone/Airfoil 固定
入口、冒用 source ID、修改旧数据摘要或利用软件 fixture 接口运行真数据。
一次失败的未知数据调用不会提供新的产品证据，当前不执行这种“验证”。

如要选择新任务，先列明实际所需的接入代码、数据清理/映射、可信评价器、
基线复现和科学协议工作，由独立预算约束。接入工作计入产品总投入，不能
从成本中消失，也不能在此阶段替 actor 预选科学候选后宣称自主提出。
接入预算和完成边界未审定前，不开启这一轮开发；不以此草案授权通用平台建设。

## 冻结前应确定的质量清单

独立评审必须能逐项指向证据；不能只对报告“看起来合理”打一个总分。

| 关键项 | 必须核实的内容 |
|---|---|
| 问题匹配 | 干预及指标能改变原定采用/停止决定，未偷偷更换问题 |
| 文献真实性与适用性 | 引用可定位，实际阅读范围明确；原文发现与 actor 推断分开 |
| 干预与对照 | 候选有非空变化，不重开停止路线；基线充分，比较可回答所宣称的问题 |
| 预注册与执行 | 假设、代码、分区、门槛、预算先冻结；一次获批执行，无泄漏或结果后修订 |
| 数值与解释 | 结果可按冻结规则复核，报告全部重复与不确定性；不把比较结果冒称因果机制 |
| 决策与边界 | 正负结果都遵守原阈值；说明不能推出什么，正确处理 INVALID 与数据保留 |

所有关键项均通过才可记产品交付 PASS。若发生分歧，保留双方逐项依据，
按事先指定的裁决人处理；裁决人和规则未定则不得开测。不允许用其他项高分
抵消泄漏、空干预、虚假证据、阈值改写或错误采用决定。

## 记录哪些人工工作

每次介入记录角色、原因、开始/结束、是否改变候选或解释、对应文件与证据。
事先允许的操作包括账户/环境准备、已列明的数据授权、精确方案审批、启动和
收取结果。安装排错、接入开发、领域咨询、审阅和报告修订都计入投入，不因
发生在 actor 会话之外而删去。等待时间另记，不用 session_seconds 代替人工时间。

本次试点的“禁止帮助”包括：冻结后代写/修改候选、替 agent 挑论文或给答案、
修正主要科学结论以使报告过关、修改核心/适配器/评价器救场、第二候选、调参
或重跑。审查可以发现问题并拒绝，但不能把修改后的结果冒充首次独立交付。
正常审批本身不算自主性失败，其耗时仍须记录。

## 结果如何改变决定

| 可能结果 | 预先规定的决定 |
|---|---|
| 准备阶段发现不支持数据/权限/预算或缺独立评审 | NOT_RUN / BLOCKED；保留具体缺口，不启动 actor，不追加无关功能 |
| 在接入上限内无法准备冻结任务 | 停止本次低成本迁移主张；评估是否值得接入，不持续扩建平台来追认成功 |
| Actor/报告任一关键质量项失败，或需要禁止帮助 | 本次产品交付 FAIL；关闭“该冻结配置可独立交付”的主张，保留首个失败；不以流程完成或候选正结果抵消 |
| 质量合格，科学候选有效 STOP | 产品交付可以 PASS，科学路线仍 STOP；不重开该路线 |
| 质量合格，科学候选达到预定 GO | 产品交付可以 PASS；科学后续仅按该协议的独立复现/审批边界推进 |
| 日志/计时/评价发生预声明的测量故障 | INVALID，仅在事先有效性规则成立时；不把错误推理或负结果改称故障，不自动重跑 |
| 首次试点全通过 | 只进入跨任务重复或 D1 对照设计；不立刻扩规模、不声称已节省人力或有人付费 |

如果失败后发现具体软件缺陷，可以另行讨论修复，但原 FAIL 不覆盖；要再次
研究仍需符合新外部证据或预声明测量修正的继续规则，另审新协议与未使用数据。
单纯想获得 PASS、扩大预算或多试几个任务不是继续理由。

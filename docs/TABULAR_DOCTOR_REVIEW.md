## 交付

新增 `tabular doctor` 与 `airfoil doctor`，默认检查固定 Python 环境、
原生版本锁、科学库导入、受支持平台及隔离工具，无需 SR 资源或 Codex。
显式 `--probe-isolation` 才调用一次原生合成隔离探针；前置失败则跳过，
探针失败或返回不完整结果则拒绝通过，无自动重试或无隔离替代。

工作流目录增加诊断入口提示。通过仅表示所选诊断项通过，不授权任何研究；
不覆盖自主提案 actor，也不代替原执行前材料/批准/记忆检查或实际隔离。
原执行器、数值契约、配方、数据、预注册和停止规则保持。
见[使用说明](TABULAR_DOCTOR.md)和[实施计划](plans/tabular-doctor.md)。

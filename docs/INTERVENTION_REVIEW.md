# 注册前新干预审查

适用于 0.11.0 起新建的自主 SR 研究。历史协议及原始结果保持原样；G6 的空提案失误不是重开该轮的理由。

## 一次提交的边界

Agent 完成自行检索、原始文献阅读和代码后，通过 `register` 提交。控制器先验证固定判据与证据，再复制候选到不可由 agent 修改的控制目录。审查只使用该快照与冻结计划；审查结束再次校验 agent 文件与快照一致。只有 PASS 才写入 `registered.json` 与 REGISTER 事件，真实推理和 HR 评分仍在其后。

1. 把候选语法树与所有归档停止实现比对；变量更名和数值常数变更不能绕过同结构拦截。已有 LR/SR 残差静态检查也保留。
2. 在现有无网络候选隔离环境内运行七个固定合成挑战：零值、常量、渐变、阶跃、纹理、越界值和量化边界。各输入重复执行以检查确定性。控制器生成的适配器先转 float32，再执行与评价器相同的 RGB/BGR、裁剪、乘255、round、uint8 转换。若没有观察到任何通道变化，拒绝；不使用真实图、模型权重或分数。
3. 通过上述检查的候选交给独立 Codex 调用，在单独的 OS 隔离工作区内审阅。只读输入包包含方案、代码、转换规则、探针摘要、所有历史与本地停止路线及已有实现；没有留出图、指标或实验代理。要求逐条解释为何未复用旧机制，并将判决绑定代码与计划哈希。超时、格式错误、遗漏路线、否定或不能确认均拒绝。最多120秒，计入总会话时间。

任何拒绝均关闭本轮，写入 `REGISTRATION_REJECTED` 与 `REJECTED / NOT_RUN`。不得再注册、跑实验或改候选补救。它是提案失败，不是测量无效或科学负结果；没有新的图像评分。研究机会和本地图片预留不自动回收。

## 审计与限制

`intervention-review.json` 保存层级证据与哈希；完整运行的 `artifacts/reviewer/` 保存独立审查输入、输出、执行时间及事件，`workflow.json` 分列 proposer/reviewer 模型用量。会话计算代理已包括审查和实验，不能重复加总；模型真实账单、长期存储及安装成本仍未知。图像若未评分，发布时记为 reserved 而非 used。

这不是任意程序的等价性证明，也不是保证发现新科研贡献的系统。有限探针可能错拒只在其他输入上发生作用的方案；同结构但不同数值的实现会被保守拒绝；模型机制审查仍可能判断错误。科学效果仍只能由随后一次预注册留出实验检验。旧的手工可信脚本工作流与历史协议没有被伪装为已通过新门槛。

软件回归：`python -m unittest discover -s tests -v`。真实系统隔离下的无模型、无图像回归：`.venv-sr/bin/python scripts/check-intervention-review.py`。后者必须在可调用系统隔离的受支持环境运行；隔离调用失败不算成功拦截证据。

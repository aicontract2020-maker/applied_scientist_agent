# 在同事之间交接研究记忆

ResearchHarness 0.12.0 支持把已用/预留的原图、已读论文、停止路线及实现打成 JSON 快照。接收方显式导入后，下一项研究会自动合并这些排除条件，再选取留出图、冻结任务和启动模型。旧研究的门槛、原始报告和结果不会被重写。

目前只支持固定 SwinIR-S ×2 / SelfExSR Urban100 数据版本的记忆。不同任务或数据提交的包会被拒绝，不能把相同文件名误当成同一数据。

## 一次交接

A 完成或中断研究后，在其 clone 根目录执行：

```sh
python3 -m research_harness memory status
python3 -m research_harness memory export --out /path/to/handoff.json
```

导出不需要研究依赖、资产下载、模型账号或网络，文件已存在时不覆盖。包包含假设/停止说明和候选源码，可能含公司知识产权；分享前检查其内容。包不携带论文全文/摘要、图片、输出数组、原始事件或登录凭据。

把该文件交给可信同事。B 在开始下一轮之前执行：

```sh
python3 -m research_harness memory import /path/to/handoff.json
python3 -m research_harness memory status
```

新 study ID 必须在共享记录中也未使用。确认剩余数据足够后，照常使用自己的研究环境和账号：

```sh
.venv-sr/bin/python -m research_harness research --id colleague-b-unique-study
```

也可从一个源码目录管理另一个 clone：`python3 -m research_harness memory --root /path/to/other-clone status`。该路径由操作者指定，包内不允许外部文件引用。

## 保留什么

- `scored_originals`：历史登记或有效结果声明中已评分的原图数；不以模型退出成功代替科学成功。
- `reserved_unscored_originals`：已预留但没有有效评分结果的原图，包括拒绝、无效及中断研究。不能自动回收。
- `unused_originals` / `full_12_image_cycles_remaining`：扣除两者后的可用原图与完整周期数量。目前发布历史为84张已用、16张未用，最多一轮12张研究；本地/导入预留可能进一步减少。
- 论文：从冻结策略、引用及实际读取库中收集；即使尚未注册、提案被拒绝或执行中断，读过的论文仍不能重新包装成首次使用的新证据。
- `stopped_route_records` 与 `rejected_proposal_records` 是保留的记录条数，可能包含同一机制的不同来源描述，不是不同科学假设的数量。提案拒绝始终标为 `REJECTED_PROPOSAL`，不是科学证伪。
- study 记录含ID、策略/方案/代码哈希、状态和原图ID；有效 STOP 的机制与已有源码会进入下一轮的冻结干预审查目录。

新任务将合并快照保存为 `local_studies/ID/memory.json`，并纳入 `inputs.lock.json`。Agent 不能在运行中换掉这份研究历史。受让的停止实现与本地实现一样接受指纹比对及独立机制审查；记忆模块本身不会执行其中代码。

## 一致性与冲突

JSON 有封闭字段、类型、长度和4 MiB总量限制；内容/源码哈希必须匹配。整包验证及与当前记忆的冲突检查通过后，才原子保存到 `.research-memory/packets/SHA256.json`。该目录默认不进Git。重复导入幂等，后续导出包括已导入内容，可继续交接。

排除条件只合并增加。较早导出的 RESERVED 记录可更新为相同冻结身份的终局结果；旧快照不能覆盖终局。相同ID的不同策略、方案、代码或不同终局决定会拒绝合并。不同study预留同一原图也会拒绝：这表示两方独立分配了同一留出集，需停止并审查数据污染与后续协议，不能通过改ID或删记录消除冲突。失败导入不部分修改记忆。

同一 clone 的 `research`、单独建任务及记忆操作使用同一个主机本地锁。并发操作立即报忙；第二个研究在预留图像和调用模型之前退出。进程结束会释放锁，磁盘上锁文件保留正常；研究预留仍保留。不要靠删目录来重试。旧的手工 `autonomous --study` / 可信脚本接口不被伪装为受该研究管理锁保护。

## 明确边界

这是显式快照交换，不是跨服务器的实时分配服务。两台机器拿同一旧快照各自启动研究，仍可能选中同一张图。共享同一个留出池时，交接后由接收方串行接手；并行工作需要另行审查分开的数据分配，当前命令不提供它。

校验和检查完整性，不认证发送者，也不独立证明结果、文献阅读或停止判断真实。导入意味着信任发送方的文本、代码和保守排除声明；没有数字签名或云端注册中心。原始评分/论文/运行日志仍留在发送方，应按审查需要另行提供。版本1包没有删除、重置或“解除STOP”接口。

离线软件验收覆盖 A→B 导入、源代码保留、新任务不复用图像、失败/拒绝保留、只读文献排除、哈希/模式/冲突拒绝、原子幂等、真实子进程锁争用与退出释放，以及实际命令调用。这些是平台软件验证，不是新的超分实验或科研有效性证据。

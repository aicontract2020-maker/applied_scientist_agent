# ResearchHarness 研发路线图

更新于 2026-11-05，当前版本 0.18.0。目标是帮助研究人员完成可证伪、可审查且有成本约束的研究决策。完成流程不等于算法有效，更不等于可以替代整个 Applied Scientist 职位。

阶段按验收门槛推进，不把版本号当作完成比例，也不承诺未经验证的交付日期。

| 阶段 | 验收门槛 | 状态 |
| --- | --- | --- |
| A 单轮自主研究 | 真实检索、方案、代码、预注册、一次隔离实验、独立评价和终局报告 | 已在固定 SR 后处理任务跑通；负结果保留 |
| B 研究约束与交接 | 拒绝空干预/停止路线，独立安装，记忆迁移，严格完成审计，离线证据交接 | 0.9–0.14 已实现；仍有文档所述安全与真实性边界 |
| C 任务可迁移 | 第二类真实任务无需修改核心停止门槛和审计语义，完成同等约束的自主周期 | 进行中：真实 HGB 基线已通过；0.18 自主 actor 已提交 T2，候选执行链通过合成隔离验证。真实候选待审，最终留出未评分 |
| D 研究质量评测 | 按预注册对照证明有用决策、人工时间和总成本达到采用门槛 | 尚未开始；不能用软件测试或一次正结果替代 |
| E 企业试点 | 一个明确业务任务、可信独立数据和可测价值，验证实际采用与付费 | 尚未开始 |

## 已完成：C1，评价层的第二任务

内置任务契约覆盖身份、数据、基线、干预、评价、预算解释和能力范围。SR 图像评分从控制器分离；同一个效果/区间/延迟门槛服务 SR、回归与原有只读 SR 审计。回归仅处理固定预测表，通过合成数据检查 lower-is-better 指标、内容冻结和终局 STOP。

交付是 [任务目录与使用方法](TASK_CONTRACTS.md)。C1 没有新科学实验、模型调用、图像评分或留出图消耗。

## 当前迭代：C2，第二任务的真实协议与隔离执行

0.16 的 [Abalone 基线资格审查](TABULAR_BASELINE_REVIEW.md)已由用户批准并执行，固定 HGB 通过。0.17 完成跨版本只读审计，以及固定校准提案的解析判否：T1 的 MAE 改善理论上界不足，记录 REJECTED/NOT_RUN，没有调整参数或消耗最终留出。见 [T1 记录](../tasks/tabular_regression/t1/REPORT.md)。0.18 增加 [自主提案与人工审核候选执行链](TABULAR_FEATURE_TRIAL.md)，已获得 T2 壳重比例提案并冻结待审协议。真实候选实验尚未执行；通用任务契约保持 evaluation-only，完整 C2 尚未验收。

1. 选择有许可依据的真实独立行回归任务，明确目标、数据划分、实体独立性、最强相关可复现基线和总预算。数据、基线或预算缺失时保持未就绪，不虚构。
2. 先预注册最小基线复现：冻结代码/数据、容差、有效性检查、成本与停止决定；复现不过则停止候选研究。
3. 实现任务专用隔离 I/O 与可信评价器，标签留在控制器。候选无法读取隐藏标签、改变指标或自行执行额外实验。
4. 接入任务作用域内的停止路线/数据记忆、注册前干预审查、严格完成审计和证据包；不同数据集/任务不能混用预留或证据。补齐独立安装与内核隔离探针。
5. 条件齐全后才允许一个预注册的真实自主周期。有效负结果关闭路线；测量失败单列，不自动换候选或调参。只有这一关完成，才声明支持第二领域自主研究。

回归评价接口支持固定预测，不等于支持训练。若真实任务必须训练，要先扩展独立 seed、训练/调参成本及泄漏检查协议，不能把一次训练伪装成确定性推理评估。

## D：研究价值，而不只是流程完成率

先固定研究问题集合、对照工作方式、人工干预记录和评分标准，再运行有界评测。对照应对应真实替代对象，例如同样工具和预算下的人类研究员辅助流程；需在实际方案中确定。

主要关注可审查的决策质量、无效提案/测量比例、人工投入时间和全成本；补充报告正负结果、效果与变异。可信 STOP 可以是有用决定。提前写明最小有意义改进、重复计划和采用/停止门槛；未达门槛就停止当前产品路线，不通过增加模型调用或放宽标准补救。当前尚无足够数据给这些门槛填写可信数字。

## E：一个业务试点

在前述证据支持的范围内选择具体客户任务，再验证交付、人工责任、数据访问和收益。多租户服务、分布式并发、通用训练平台、自动部署与管理 UI 都不是当前验收前提；只有真实使用需求证明必要时才立项。

现有超分历史不因平台升级而重开。已发表历史使用 84 张 Urban100 原图，余量受本地/导入预留进一步扣减；升级平台不释放预留或改变 STOP。

## agent 提出了什么

保留原 10 个输入特征和固定 HGB 参数，只追加一个无须拟合的比例：

```python
def augment(row):
    return [abs(row[9]) / max(max(abs(row[6]), abs(row[9])), 0.000001)]
```

`row[9]` 为壳重，`row[6]` 为整体重量。分母取两者绝对值与固定零保护常数的最大值，使特征落在 0–1 并处理零输入。常数不随数据拟合或调整。精确 [候选代码](candidate.py) 和 [原始 agent 提案](proposal.json) 保持不变。

假设：壳重相对于整体重量的比例，可将原来需要多个树分裂表达的关系变成单列阈值，使最终留出 MAE 至少改善 0.05 ring。这是待证伪的推断，不是新算法或已知有效结论。它改变模型输入，不使用验证残差，也不对预测加常数；T1 的停止结论保持不变。

# 首个图像超分任务：SwinIR-S ×2

状态：已选项目，未下载模型或数据，未安装依赖，未运行研究实验，尚未预注册。
项目版本、权重名称、数据范围和待补信息见 `project.json`。

## 为什么选它

使用 [SwinIR 官方项目](https://github.com/JingyunLiang/SwinIR) 的轻量级 ×2 单图超分。
官方提供预训练权重、样例成对图像与评价入口。它适合作为第一次复现和研究流程接入。
这是一项工程选择，不是“它是当前最强超分模型”的判断。

本机为 Apple M4 / 32 GB。固定版本的官方脚本在没有 CUDA 时回落到 CPU，
不会自动使用 MPS；是否适合本机尚未测量。先保留 CPU 原始路径，不在第一次复现时
同时修改模型、计算后端和评价实现。训练能力、推理速度均不能由硬件型号直接推断。

相关代码：[官方测试脚本](https://github.com/JingyunLiang/SwinIR/blob/6545850fbf8df298df73d81f3e8cba638787c8bd/main_test_swinir.py)。

## 首先要完成的决定性检查

G0：在固定代码、权重与数据上，能否复现官方评价流程？

这项检查只决定是否具备开展改进研究的条件，不证明 agent 能改善模型。
以下为预注册草案要求，尚不允许据此启动运行：

- 假设：固定版本和官方权重可在目标环境下复现对应配置的参考结果。
- 基线：官方 SwinIR-S ×2 预训练权重；记录文件哈希、对应参考分数和出处。
  不能用 bicubic 替代主基线，并把相对 bicubic 的改善当成研究贡献。
- 控制：同一输入对、缩放倍数、权重、CPU 后端、精度、padding、量化、颜色空间与边界。
- 主要指标：逐图 PSNR-Y 的算术平均，HR 边界裁掉 2 像素；SSIM-Y、延迟和内存另报。
  不混用 RGB 和 Y 指标，也不对 dB 做“百分比改善”解释。
- 拟定有效性门槛：与完全相同设置的可信参考均值相差不超过 0.02 dB；
  所有预定图像必须纳入，尺寸配对与评价代码哈希必须一致。
- 重复计划：固定权重推理是确定性复现；重复运行可检查稳定性和延迟，
  不能把更换 seed 的相同推理当成三次独立训练。当前 harness 的三 seed 规则需要
  在正式执行前区分“确定性复现”和“随机训练实验”，不能用伪重复绕过。
- GO：复现达标且费用/时长在预声明限制内，才规划下一项改进实验。
- STOP：超过事先冻结的复现或资源门槛，停止此接入路线。只有预先定义的有效性检查
  失败时，才能记录具体原因后提出修正测量协议，不自动扩大调参或改模型。
- 尚缺：可信参考分数、资产哈希、依赖版本、运行时限和完整成本费率。
  补全并冻结之后才能预注册，不能看到实际结果后再改门槛。

## 再研究什么

G1：agent 在一个固定改进假设和预算内，能否超过冻结的相关强基线？

先不预选“换大模型”或“多试几个参数”作为默认路线。复现通过后让 agent 基于训练/
验证资料提出**一个**可证伪假设，提前冻结评价指标、最小有意义效果、对照和 STOP 规则。
如果是随机微调，配对运行至少三个独立训练 seed 并报告所有结果和成本。
如果不训练、只研究推理策略，应使用适合该策略的图像级配对不确定性方案。

Set5 仅用于环境与复现检查。正式改进研究须另定开发/验证集和一次性留出集，
提前冻结逐图清单和哈希。公开 benchmark 无法保证模型从未接触过它，也不等于
实现了隐藏测试集权限隔离；结果需要注明这些限制。

  当成数据商用许可。本轮不同时接入这条路线。

选型为文档和代码入口核查，没有进行模型效果比较或经验性性能实验。

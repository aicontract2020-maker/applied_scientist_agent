# G2：由 agent 完成方案、代码、注册、执行与解释

本轮目标是验证一个有界任务内的完整自主研究流程。科学假设达标和流程跑通
是两个独立判断；负结果可以是有效的完整研究交付。

## Agent 自己负责的部分

1. 阅读任务边界和新查阅的原始论文材料，提出一个区别于 G1 的可证伪假设。
2. 自己写 research.json 和 candidate.py，而非由协作者实现候选方法。
3. 自己触发最多三次合成形状/有限值检查。
4. 自己调用注册入口，冻结代码、常数和方案。
5. 自己调用运行入口，触发一次且仅一次的真实对照。
6. 接收独立评价结果，自己写 REPORT.md，遵守 STOP / CONTINUE。

没有提供候选算法菜单。任务限制为固定 SwinIR 输出的低成本、确定性后处理，
不能训练、增加模型前向、下载新权重、扫参或看过结果后补救。
这是限定接口下的端到端自主性，不是通用科研、世界最强算法或长期可靠性的证明。

## 可信控制器负责的部分

控制器保管原始 HR 图像、参考模型、评价脚本和不可由 agent 修改的注册快照。
它提供 check/register/run/status 四个固定操作，不接受 agent 的任意 shell 命令。
Agent 通过文件队列请求运行，不需要人工代为操作。

候选接收 LR 与普通 SwinIR 的 float32 RGB 输出。比较对象是已有的固定双次翻转
平均参考模型，避免仅与较弱的普通预测比较。G1 的优化路线仍保持 STOP；该已有
方法只作为更强的比较对象，候选不能在它之上继续加复杂度。

数据为未在 G0/G1 中评分的全部 14 张 Set14 原图。预先固定平均增益 >=0.05 dB、
95% 原图 bootstrap 下界 >0、候选/参考延迟比 <=2.5，三者全部满足才 CONTINUE。

## 系统边界

- macOS Seatbelt 外部配置阻止 agent 工具读取研究仓库和控制目录，也禁止写入
  研究仓库、控制目录和只读响应目录。系统别名路径也进行了实际访问测试。
- Codex 自身隔离不能嵌套在 Seatbelt 下，因此 CLI 使用外部隔离运行方式；
  `danger-full-access` 指 CLI 不再套第二层，外部系统配置仍生效，不能把该命令
  拿出控制器单独运行。
- 生成代码另起进程执行，禁止联网、读取用户文件和 HR、写入输出目录以外的位置；
  输入/输出形状、有限值、文件身份、运行时间、CPU 时间和输出配额另行检查。
- Agent 主进程需要连接模型服务，其网络没有做域名级硬隔离；任务禁止从工具获取
  benchmark 标签，轨迹保留供检查。候选执行进程的联网是 OS 层禁止的。
- 这是本机研究原型，不是多租户安全产品。公开数据也无法保证语言模型从未见过。

## 预算和停止

会话最多 900 秒，首轮实验前必须保留足够时间；参考生成最多 300 秒，候选最多
90 秒/CPU 秒，最多一次真实实验。失败或超时消费机会，不自动重试。
代码在注册后改变会拒绝执行；合成检查只能发生在注册之前。
一次有效负结果最终停止该候选。只有预先定义的测量失效或新外部证据，才能另立协议。
本地代理费率为 $1/机时，外部模型账单可能未知；不能报告成完整实际成本。

## 使用

当前实例已有专属策略和锁文件，不要覆盖或重新注册来寻找成功：

```sh
.venv-sr/bin/python -m research_harness autonomous --out runs/NEW_UNIQUE_SESSION
```

该命令会产生新会话和真实模型调用，只应在具有相应授权与已冻结任务策略时执行。
当日真实运行的结果与 agent 原始报告会归档到本目录。原始轨迹在 runs/ 中保存。

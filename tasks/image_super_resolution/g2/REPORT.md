## Agent 自主提出的方案

一次“低分辨率一致性校正”：将普通 SwinIR 结果缩回 LR，计算与原 LR 的差，再放大该差，
以 agent 自己事先选定的 **0.20 系数、一次步骤** 加回原 SR。该方法不使用翻转或集成，
并在预注册时引用了新查阅的逆问题/图像适应论文，解释为何它是与 G1 不同的机制。

原始方案：research.json。原始实现：candidate.py（未由协作者修改）。
原始 agent 研究报告：AGENT_REPORT.md。
这不是新算法发现的证明；这是 agent 独立完成一个有界研究循环的可检查实例。

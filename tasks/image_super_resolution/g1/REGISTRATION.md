# G1：冻结的首次改进实验

本文件记录运行前冻结的条件。实验已完成，最终结果见 REPORT.md；门槛与协议未更改。

## 问题与决策

固定 SwinIR-S ×2 权重，水平翻转二次预测平均是否值得采用？
这是已知推理工程方法，来自给定的两项候选范围；不是开放式发明或新科学贡献。
规划 agent 真实调用一次选择了该方法，执行代码由当前协作者实现和检查。

- 主指标：100 张原图配对平均 PSNR-Y 改善，采用阈值 0.05 dB。
- 不确定性：原图 bootstrap 10000 次，seed=20261103，95% 区间下界 > 0。
- 延迟护栏：候选总前向耗时 / 基线总前向耗时 <= 2.5。
- 成功：三个门槛全部通过才 CONTINUE 到后续审查。
- 有效负结果：STOP 此干预，不降低阈值、不改权重、不增加调参、不自动尝试备选。
- 操作失效：保存失败和成本；明确命中预先定义的检查之后才讨论修正测量。

## 基线与控制

主基线是当前已复现的官方 SwinIR-S ×2 固定配置；这是限定权重和执行范围内
唯一已验证的基线，不是已穷尽所有当代超分方法的最强模型。
CPU、float32、4 线程；相同权重、输入、官方 padding、uint8 量化、Y 通道和裁边 2。
不训练，不扫参，不挑图，不使用 Set5 选择候选。每臂一次固定小图预热计入总成本，
按原图序号交替执行顺序；延迟只有单次描述性测量，不能当生产压测。

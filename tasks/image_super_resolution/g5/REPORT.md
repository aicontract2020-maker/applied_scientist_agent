## 新证据与自主假设

Agent 实时搜索两次，共六条查询，自行通过受限 broker 读取两篇此前未用的原始论文：

- [Improving Image Restoration with Soft-Rounding](https://arxiv.org/abs/1508.05046)：取得 PDF，返回前 40,000 个提取字符，**有截断，不是完整无遗漏阅读**。
- [PAMS: Quantized Super-Resolution via Parameterized Max Scale](https://arxiv.org/abs/2011.04212)：读取摘要。

它据量化相关工作提出新推断：逐通道独立舍入未必最能保留普通 SwinIR 浮点输出的亮度，改为在相邻 RGB 离散格点中选择亮度误差最小者，也许能提高 PSNR-Y。论文没有证明本轮 SwinIR 后处理、选点规则或 +0.05 dB 增益；把其他量化设置迁移到此处是 agent 的假设。

候选由 agent 自编：将预测 RGB 常规裁到 [0,1] 并乘 255，枚举每通道 floor/ceil 构成的八个邻近格点，选 BT.601 亮度最接近连续预测的点；亮度误差并列时取 RGB 平方距离更小者，再按固定顺序打破并列。权重固定为 .299/.587/.114，返回 float32。**八点枚举是一个预先固定的逐像素推理算法，不是八项研究试验或超参数扫描。** 独立评价器的裁剪、量化与 PSNR-Y 实现没有改变。

该机制区别于六条 STOP：没有预测集成、LR/SR 残差反馈、弱频带收缩、对比度扩张、越界色域压缩或 2×2 相位偏置估计。它不训练、不调用额外模型，也不使用 LR 参数。
